# Web-App-Assistant

This project is an intelligent banking assistant designed to simplify user interaction with financial services. The chatbot understands user queries, provides detailed information, and guides users through applying for banking products.

## Key Features

- **Product & Service Information**  
  Answers user queries about a wide range of banking products and services, including:
  - Credit/Debit cards
  - Bank accounts (savings, current, etc.)
  - Loans (personal, home, auto, etc.)
  - Investment options

- **Personalized Recommendations**  
  Collects relevant user information and recommends banking products or services tailored to individual needs.

- **Application Support**  
  Gathers all necessary information from the user to initiate applications for products or services they’re interested in.

- **Smart Redirection**  
  Seamlessly redirects users to the appropriate web pages for detailed info or to complete their application.
